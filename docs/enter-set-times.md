# Entering the official set times

Warped releases stage assignments and set times close to (or during) the show. When the schedule banner drops, one person types it in fast, then shares it with the group.

## Fast entry

1. **Schedule tab → Edit Times.**
2. Pick the day (**Sat / Sun**).
3. Two layouts (toggle top-left):
   - **Artist list** — every artist for the day; set a **Stage** and **Start** (End optional) inline.
   - **Stage timeline** — grouped by stage; add times under each stage column.
4. Use the search box to jump to an artist, and the **No stage / No time** filters to see what's left.
5. Everything **saves instantly**. The completion bar shows how far along you are.
6. **Undo** reverts the last change.

Time entry is forgiving — `3:05 pm`, `15:05`, `1505`, and `3 pm` all work.

The app warns you if two performers are put on the same stage at the same time, and never overwrites an exact end time you typed.

## End times

- Type an exact **End** when you know it.
- If you leave End blank, the app **estimates** it from the next set on that stage (minus a turnover buffer you can set under **Menu → Travel & Crowd**). Estimated ends are always labeled “est.”

## Share it with the crew

After entering, **Menu → Schedule Import / Export → Export**, and send the QR/code to the others so they don't each have to type it. See [data import/export](data-import-export.md).

## Photo import

Reading the schedule from a photo (OCR) is intentionally **not** included — the manual editor is faster and can't silently guess a wrong stage or time. If it's ever added, any photo-read result must be reviewed by a person before saving.
